# WishMate (위시메이트)

> 갖고 싶은 건 위시리스트에, 선물은 함께.

이 문서는 서비스 아이디어와 MVP의 핵심 사용자 경험을 정리한 프로젝트 README다.
구현 방법은 코드 작성 과정에서 결정하며, 아래 기능이 이미 구현되었다는 뜻은 아니다.

## 1. 프로젝트 개요와 핵심 컨셉

WishMate는 원하는 상품을 위시리스트에 모으고 친구에게 공유하는 선물 서비스다.
친구는 목록에서 상품을 골라 혼자 선물하거나, 여러 사람과 공동선물을 준비한다.

- 서비스의 시작점과 중심은 **위시리스트**다.
- 상품 저장 버튼은 **위시리스트에 추가하기**로 통일한다. `찜하기`는 사용하지 않는다.
- 친구의 위시 항목에는 **선물하기**와 **공동선물 시작하기** 버튼을 각각 직접 보여준다.
- 하나의 위시 항목에는 하나의 선물 흐름만 진행할 수 있다.
- 결제와 구매는 모두 데모이며, 실제 돈이나 상품이 오가지 않는다.

## 2. 사용자 구분

같은 회원도 자신의 목록에서는 선물 받는 사람, 친구의 목록에서는 선물하는 사람이 된다.

| 구분 | 할 수 있는 일 | 제한 |
| --- | --- | --- |
| 로그인 회원 | 내 위시리스트 관리·공유, 바로 선물, 공동선물 개설·참여 | 다른 사람의 목록은 수정할 수 없음 |
| 이메일 인증 참여자 | 인증한 공동선물 참여, 본인 참여 내역 확인 | 위시리스트 관리·바로 선물·공동선물 개설 불가 |
| 비회원 | 상품 탐색, 공유 링크로 목록과 진행 상황 확인 | 참여하려면 이메일 인증, 회원 기능은 로그인 필요 |

### 공통 화면 원칙

- 사용자 유형별로 별도 사이트나 화면을 만들지 않는다.
- 공통 화면에서 로그인 여부, 소유권, 참여 여부에 따라 메뉴와 버튼만 바꾼다.
- 자신의 위시 항목에는 관리 기능을, 친구의 항목에는 가능한 선물 기능을 보여준다.
- 자기 위시 항목에는 바로 선물하거나 공동선물을 개설할 수 없다.

## 3. 선물 받는 사람 흐름

상품 탐색 → 위시리스트에 추가하기 또는 직접 상품 등록 → 목록 관리 → 공유 → 결과 확인

### 3.1 상품 탐색

- 상품 목록에서 카테고리와 상품 정보를 살펴본다.
- 관심 있는 상품을 선택해 이미지, 가격, 설명, 상품 링크를 확인한다.

### 3.2 위시리스트에 추가하기

- 상품 상세에서 **위시리스트에 추가하기**를 누른다.
- 회원마다 기본 위시리스트 한 개를 사용한다.
- 이미 추가한 상품은 **위시리스트에 추가됨**으로 표시한다.
- 같은 기본 상품을 중복 추가하지 않으며, 새로고침해도 목록을 유지한다.

### 3.3 직접 상품 등록

- 필수 입력: 상품명, 가격.
- 선택 입력: 상품 이미지(파일 업로드 또는 URL 입력), 상품 링크, 카테고리, 설명, 원하는 이유 또는 메모.
- 카테고리는 기본 상품과 같은 네 가지를 사용하며, 분류하기 어려우면 기타를 선택한다.
- 직접 등록 상품은 내 위시 항목으로만 관리하고 공용 상품 목록에는 추가하지 않는다.
- 상품 이미지는 기기에서 파일을 업로드하거나 이미지 URL을 입력해 등록한다.
- 이미지가 없거나 불러올 수 없으면 기본 이미지(fallback)를 보여준다.

### 3.4 목록 관리

- 목록 제목, 소개, 공개 범위를 수정한다.
- 목록 전체 공개 범위와 별도로 각 위시 항목의 **공개 / 비공개**를 관리한다.
- 선물 시작 전에는 소유자가 상품별 공개 여부와 메모를, 직접 등록 상품은 상품 정보도 수정할 수 있다.
- 혼자 선물하기 또는 공동선물이 진행 중인 상품은 공개 여부를 포함해 수정·삭제할 수 없다.
- 선물 방식은 받는 사람이 미리 설정하지 않고, 선물하는 사람이 선택한다.

| 상품 상황 | 친구의 공유 위시리스트 | 소유자의 내 위시리스트 |
| --- | --- | --- |
| 선물 시작 전 + 공개 | 표시, 두 선물 방식 중 선택 가능 | 표시, 수정·삭제 가능 |
| 선물 시작 전 + 비공개 | 숨김 | 표시, 수정·삭제 가능 |
| 혼자 선물 진행 중 또는 공동선물 모집 중 | 공개 상품만 표시, 새 선물 시작 불가 | 표시, 수정·삭제 불가 |
| 혼자 선물 완료 | 자동 비공개 | 유지, 받은 선물/완료 내역에서도 확인 |
| 공동선물 목표 달성 | 즉시 자동 비공개 | 유지, 최종 완료 후 받은 선물/완료 내역에서도 확인 |

비공개 상품은 소유자에게만 보이며, 선물 관련 데이터와 완료 기록은 삭제하지 않는다.
자동 비공개는 이미 선물이 확정된 상품을 다른 사람이 다시 선물하려는 상황을 막기 위한 처리다.
완료된 항목도 새 선물 시작과 수정·삭제를 막는다.

### 3.5 위시리스트 공유

- 기본 공개 범위는 **링크 공유(UNLISTED)**다.
- 링크 공유 목록은 링크를 가진 사람만 조회할 수 있다.
- 사용자가 원하면 **비공개**로 변경할 수 있다.
- 비공개 목록은 링크를 알아도 소유자만 볼 수 있다.
- 공유 목록에는 공개 상품만 보여주며, 비공개 상품의 존재 여부나 개수는 친구에게 노출하지 않는다.
- 공유 방법은 다음 세 가지다.
  - 링크 복사
  - QR 코드 공유
  - **기기의 기본 공유 창으로 위시리스트 링크 공유**
- 기본 공유 창은 모바일 또는 지원되는 브라우저에서 운영체제/기기의 기본 공유 UI를 연다.
- 별도의 카카오톡 SDK나 SNS 전용 공유 기능을 구현한다는 의미는 아니다.
- 전체 공개 위시리스트 검색은 MVP에서 제공하지 않는다.

### 3.6 선물 결과 확인

- 혼자 선물 또는 공동선물이 최종 완료되면 **받은 선물/완료 내역**에서 결과를 확인한다.
- 진행 중인 공동선물의 상세 참여 금액과 참여자 정보는 받는 사람에게 보여주지 않는다.
- 받는 사람에게는 진행률·준비된 금액·닉네임·메시지로 준비 상황을 드러내지 않는다.
- 항목 수정·삭제가 제한될 때도 누가 얼마를 준비하는지 밝히지 않고 필요한 안내만 제공한다.
- 완료 후에는 선물과 공개 메시지를 확인하되, 타인의 개인별 참여 금액은 계속 숨긴다.

## 5. 선물하는 사람 흐름

친구의 공유 위시리스트 → 위시 항목 상세 → 선물하기 또는 공동선물 시작하기 선택

### 5.1 선물 방식 선택

- 공유 목록의 공개 상품에 **선물하기**와 **공동선물 시작하기** 버튼을 각각 직접 노출한다.
- 선물하는 사람이 원하는 버튼을 선택하며, 두 기능 모두 로그인 회원만 시작할 수 있다.
- 시작 전에는 두 버튼이 함께 보이지만, 한 흐름이 시작되면 새로운 선물을 시작할 수 없다.
- 혼자 선물하기 진행 중에는 공동선물 시작이, 공동선물 진행 중에는 혼자 선물하기가 불가하다.
- 이미 진행 중인 선물은 해당 진행 상황으로 안내한다.

### 5.2 바로 선물하기

1. **선물하기**를 선택한다.
2. 상품과 전체 금액을 확인한다.
3. 선물 메시지를 입력한다.
4. 데모 결제·구매 처리를 진행한다.
5. 선물 완료 시 상품을 자동 비공개로 바꾸고 결과를 확인한다.

한 사람이 상품 전체를 준비하며, 공동선물 모집이나 참여 기록은 만들지 않는다.

### 5.3 공동선물 시작하기

1. **공동선물 시작하기**를 선택한다.
2. 목표 금액과 모집 기간을 설정한다.
3. 공동선물을 생성한다.
4. 참여 링크를 공유한다.
5. 참여자를 모집한다.
6. 목표 금액 달성 시 상품을 자동 비공개로 바꾼다.
7. 데모 결제·구매 처리를 진행한다.
8. 완료 결과를 확인한다.

참여가 한 번이라도 발생하면 목표 금액을 바꿀 수 없다.

### 5.4 모집 기간

- 기간은 공동선물을 시작할 때 개설자가 설정하는 **모집 기간만** 관리한다.
- 상품 등록 폼과 위시 항목에는 기간 입력이나 표시를 두지 않는다.
- 개설자는 목표 달성 전이면서 모집 기간이 끝나기 전에 최대 한 번 연장할 수 있다.
- 목표 달성 또는 모집 종료 후에는 연장할 수 없다.

### 5.5 공동선물 취소

- 공동선물은 개설 후 참여 여부와 관계없이 개설자를 포함한 누구도 직접 취소할 수 없다.
- 취소되는 유일한 경우는 모집 기간이 끝날 때 목표 금액에 도달하지 못한 경우이며, 이때 자동 취소한다.
- 취소된 공동선물에는 추가 참여를 받지 않는다.

## 6. 공동선물 참여 흐름

참여 링크 → 로그인 또는 이메일 인증 → 참여 정보 입력 → 목표 달성 → 데모 처리 → 완료

### 6.1 이메일 OTP 인증

- 로그인 회원은 로그인 상태로 참여한다.
- 비회원은 이메일로 받은 **6자리 일회용 인증번호(OTP)**를 입력한다.
- 이메일 인증만으로 참여할 수 있으며 회원가입은 필수가 아니다.
- 인증은 해당 공동선물에만 유효하며, 다른 공동선물에서는 다시 인증한다.
- 인증이 만료되면 참여·본인 내역 조회·재시도 전에 같은 이메일로 다시 인증한다.

### 6.2 참여 금액·닉네임·메시지

- 참여 금액과 닉네임을 입력하고, 원하는 경우 메시지를 남긴다.
- 제출 전에 실제 결제가 없는 데모 참여임을 안내한다.
- 참여 금액은 원 단위이며, 0원보다 크고 목표까지 남은 금액 이하여야 한다.
- 모집 기간 중에만 참여할 수 있고, 전체 참여 금액은 목표를 넘을 수 없다.
- 같은 사람도 여러 번 참여할 수 있으며 본인의 전체 참여 내역을 확인한다.
- 제출한 참여 금액·닉네임·메시지는 수정하거나 취소할 수 없다.
- 다른 사용자는 공유 범위 안에서 참여자 닉네임과 공개 메시지만 볼 수 있다.
- 단, 선물 받는 사람에게는 완료 전까지 참여자 정보와 메시지를 숨긴다.
- 개인별 금액과 이메일은 진행 중과 완료 후 모두 타인에게 공개하지 않는다.
- 본인은 자신의 참여 금액과 처리 결과를 확인할 수 있다.

### 6.3 목표 달성 및 데모 처리

- 목표 금액에 도달하면 추가 참여를 마감하고 해당 상품을 공유 위시리스트에서 즉시 숨긴다.
- 자동 비공개 시점은 최종 데모 구매 완료가 아닌 목표 금액 달성 시점이다.
- 목표 달성 후 데모 결제 처리와 데모 구매를 진행한다.
- 완료 후에는 선물 받는 사람도 상품과 참여자들의 공개 메시지를 확인할 수 있다.
- 화면에는 **데모 결제 처리 완료**, **데모 선물 준비 완료**처럼 시연임을 명시한다.

### 6.4 실패와 모집 종료

- 데모 결제 처리 실패는 취소 사유가 아니며, 실패 안내와 재시도 흐름을 제공한다.
- 해당 공동선물에 참여 기록이 있는 사람만 결제 처리를 재시도할 수 있다.
- 개설자나 받는 사람도 참여 기록이 없다면 재시도할 수 없다.
- 모집 기간이 끝날 때 목표 금액에 도달하지 못하면 모집을 종료하고 공동선물을 자동 취소한다.
- 모집 종료 후에는 추가 참여를 받지 않는다.
- 실제 결제가 없는 MVP이므로 환불 기능을 구현하지 않는다.

## 7. 주요 화면

| 화면 | 핵심 내용 |
| --- | --- |
| 메인 | 서비스 소개, 상품 탐색과 위시리스트 진입 |
| 상품 목록·상세 | 네 가지 카테고리, 상품 정보, 위시리스트에 추가하기 |
| 로그인·회원가입 | 이메일과 비밀번호를 이용한 회원 기능 진입 |
| 위시리스트·위시 항목 상세 | 소유자는 비공개 상품도 관리, 친구는 공개 상품만 조회·선물 |
| 직접 상품 등록·수정 | 상품 정보·메모 입력, 이미지 파일 업로드 또는 URL 입력 |
| 바로 선물 | 메시지 입력, 데모 결제·구매, 결과 확인 |
| 공동선물 개설 | 목표 금액과 모집 기간 설정 |
| 공동선물 상세·참여 | 선물하는 사람에게 진행률·남은 기간, 인증·참여 입력·본인 내역 제공 |
| 선물 결과 | 권한에 맞는 처리 결과와 가능한 재시도 |
| 받은 선물/완료 내역 | 내 위시리스트에 유지된 완료 상품과 공개 메시지 확인 |

- 빈 목록에는 상품 탐색이나 직접 등록으로 이어지는 안내를 둔다.
- 로딩, 입력 오류, 처리 중, 접근 불가 상황을 쉬운 말로 설명한다.
- 모바일과 데스크톱에서 핵심 흐름을 사용할 수 있게 한다.

- 완료 후에는 **친구들이 함께 준비한 선물이에요**처럼 결과를 안내한다.
- 실제 결제나 배송이 이루어진 것으로 오해하지 않도록 데모임을 함께 표시한다.

## 8. 핵심 데이터 관계

| 관계 | 의미 |
| --- | --- |
| 회원 → 위시리스트 | MVP에서는 회원 한 명이 기본 목록 한 개를 가짐 |
| 위시리스트 → 위시 항목 | 목록 하나에 여러 상품을 담음 |
| 기본 상품 → 위시 항목 | 같은 상품을 여러 회원이 각자 추가할 수 있음 |
| 직접 등록 상품 → 위시 항목 | 공용 상품과 연결하지 않고 내 목록에 등록함 |
| 위시 항목 → 바로 선물 또는 공동선물 | 한 항목에서 한 선물 흐름만 진행함 |
| 바로 선물 → 선물하는 회원·받는 회원 | 한 사람이 상품 전체를 준비함 |
| 공동선물 → 개설 회원·받는 회원 | 다른 회원의 위시 항목을 대상으로 개설함 |
| 공동선물 → 참여 기록 | 여러 참여 기록을 가지며 회원 또는 인증 이메일과 연결됨 |

바로 선물 기록과 공동선물·참여 기록은 구분한다.
모집 기간은 공동선물에만 속하며, 위시 항목에는 기간을 두지 않는다.

## 9. MVP 범위

### 포함

- 이메일·비밀번호 회원가입, 로그인과 로그아웃.
- 데모 상품 10개 탐색, 위시리스트 추가와 직접 등록·관리.
- 직접 등록 상품의 이미지 파일 업로드와 이미지 URL 입력.
- 회원당 위시리스트 한 개, 목록 전체 공개 범위와 상품별 공개·비공개 설정.
- 혼자 선물 완료·공동선물 목표 달성 시 자동 비공개, 소유자 항목과 선물 기록 유지.
- 두 버튼으로 바로 선물 또는 공동선물 시작, 권한에 맞는 진행 상황과 받은 선물 확인.
- 이메일 OTP 참여, 본인 내역, 개인별 금액 비공개.
- 개설 후 직접 취소 불가, 목표 달성 전·모집 종료 전 최대 1회 기간 연장.
- 모집 기간 종료 시 목표 미달인 공동선물만 자동 취소, 데모 결제 실패와 참여자 재시도.
- 실제 결제 없이 목표 달성부터 구매 완료까지 시연.

### 제외

- 실제 결제·송금·환불·정산.
- 실제 상품 주문·배송.
- 외부 쇼핑몰 API와 가격·재고 연동.
- 회원 탈퇴.
- 관리자 기능.
- 전체 공개 위시리스트 검색.
- 여러 위시리스트, 소셜 로그인, 자동 알림 등 확장 기능.
