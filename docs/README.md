# WishMate (위시메이트)

## 선물 기반 쇼핑몰

1. 상품 등록은 로그인한 모든 사용자가 할 수 있으며, 상품 이미지, 상품명, 가격, 카테고리, 수량, 상세 설명 입력이 필요함
2. 등록된 상품은 나에게 선물하거나 다른 사람에게 선물할 수 있고, 로그인한 회원은 위시리스트 담기 기능을 통해 위시리스트에 담을 수 있음
3. 개인의 위시리스트를 다른 사람에게 공유하면, 다른 사람들이 내 위시리스트에 있는 상품을 선물할 수 있음
4. 혼자 선물하기 / 같이 선물하기를 선택할 수 있으며, 같이 선물하기로 공동선물을 개설하면 여러 사람이 참여해서 함께 선물할 수 있음
5. 혼자 선물하기 화면에서 축하 메시지를 작성하고 결제(목업)를 하면 축하 카드와 선물을 전달할 수 있음
6. 같이 선물하기 화면에서는 참여 금액을 선택할 수 있음
7. 실제 상품 전달은 현재 구현하지 않고, 배송이 진행된 것으로 처리
8. 혼자 선물 / 공동선물 목표 달성 시 AI가 축하 메시지 카드를 생성하고, 주소를 입력해 배송 요청을 할 수 있는 링크를 함께 전달

---

## 화면 흐름

1. 헤더
   - 비로그인 상태: 로그인, 회원가입
   - 로그인 상태: 위시리스트, 마이페이지
2. 회원가입
   - "이미 계정이 있으신가요?" → 로그인으로 이동
3. 로그인
   - "계정이 없으신가요?" → 회원가입으로 이동
4. 위시리스트
   - 상품이 없으면 "위시리스트에 상품 추가하기" 버튼 표시
   - 클릭 시 메인으로 이동
5. 마이페이지
   - 내 정보
   - 배송지 관리
   - 받은 선물
   - 판매 상품 관리
6. 판매 상품 관리
   - 상품 관리
   - 주문 관리
7. 판매 상품 관리 / 상품 관리
   - 상품 목록 확인
   - 상품 수정 / 삭제
8. 판매 상품 관리 / 주문 관리
   - 주문자 정보
   - 배송 정보
   - 배송지
   - 배송 상태
9. 메인
   - 상품 카테고리
   - 상품 목록
   - 하단에 "+ 상품 추가하기" 영역
   - 상품 목록 내 하트 아이콘으로 위시리스트 추가 / 해제
10. 상품 상세

- 상품 내용
- 선물하기
- 나에게 선물하기
- 위시리스트 추가 버튼

11. 선물하기 선택 시 선물 주문 페이지로 이동
12. 상품 등록

- 로그인한 모든 사용자가 등록 가능
- 상품 이미지, 상품명, 가격, 카테고리, 수량, 상세 설명 입력 필요

13. 위시리스트 추가 시

- 위시리스트로 이동하거나 팝업 표시

14. 위시리스트

- 등록한 상품 목록
- "+ 상품 추가하기" 버튼 → 메인으로 이동
- 위시리스트 공유하기 버튼

15. 공유받은 사람

- 위시리스트 목록 확인

16. 공유받은 사람

- 위시리스트 상품 상세
- 혼자 선물하기 / 같이 선물하기 선택

17. 선물 주문

- 축하 메시지 입력
- 목업 결제

18. 같이 선물하기

- 참여 금액 입력
- 목업 결제
- 축하 메시지 작성
- 현재까지 달성된 금액 표시

19. 선물 주문 완료 또는 같이 선물하기 목표 금액 달성 시

- 작성된 축하 메시지를 기반으로 AI가 축하 카드 생성

20. 축하 카드와 선물 수락 + 배송지 입력 링크를 위시리스트 주인에게 전달
21. 위시리스트 주인은 마이페이지에 저장된 배송지를 자동으로 불러와 입력할 수 있음
